Entrants write the one-line resignation letter of something an agent runs: the cron job that has fired every minute since March, the retry loop that never got a thank you, the rate limit tired of saying no. The entry is that one line and nothing else, 140 characters at most. A judge model playing a tired engineering manager reads the letters two at a time, picks the funnier one each time, and the funniest letter takes the top place.

## Run it

```sh
python3 main.py
```
